# ラフカ語辞書

ラフカ語プロジェクト専用の辞書公開リポジトリです。**ラフカ語の語彙はこの Web 版辞書で一括管理します（2026-09-18 決定）。** 作業フォルダー側の Markdown 辞書（旧 `ラフカ語辞書.md`）は廃止し、語彙の追加・修正はすべてこの辞書の編集機能で行います。

**[辞書を開く](https://jinubbbo5454-rgb.github.io/lafca-dictionary/)**

- 旧統一辞書から整理した663項目と、文法から補足した生産的な接辞6項目を初期収録。以後の追加・修正は `edits.json` に記録します。
- 人名68語（男性40・女性28）を収録。借用人名42語と固有人名26語のタグは「人名」に統一しています。資料の性・語幹・祖語型を保持し、単数の五格を表示します。
- 品詞は名詞・代名詞・動詞・形容詞・連体詞・副詞・前置詞・接続詞・小辞・間投詞。接辞・慣用句は項目種別で選び、基数・序数は品詞を横断して絞り込めます。
- 品詞・性・型による絞り込み、変化形からの検索。動詞は「活用」、それ以外の屈折語は「曲用」で語形表を表示。
- 名詞の固定・Ⅰ・Ⅱ型、動詞の交替種類・非交替・母音幹・不規則、形容詞の語幹型を表示。
- `manča`・`bidašta`・`höri` は男性・複数のみの独立名詞として収録し、対応する語からリンクで参照できます。`fissa` や人名など105語は「複数形なし」と表示し、単数の五格だけを収録します。
- `-aq`派生名詞や`čaq`の曲用も収録。規則的な動名詞は独立見出しにせず、元の動詞の語形として扱います。`gessad`・`humad`・`sibad` の曲用は `gassen`・`homen`・`seben` の活用欄で参照できます。
- 総称や構文説明を見出しにせず、独立した意味・用法の根拠がある語彙だけを登録。語形の明記や定型句の一例だけでは語彙化と認定しません。非生産的な `-ča` と化石的な `-t-` は独立登録せず、`horča` などの派生語を収録。
- 祖語型は「祖語型：*…」に統一し、原資料の注記や表外の語形は表示しません。母音幹の曲用・活用と子音接合を含め、すべての語形を収録しています。無主語動詞の存在しない人称形・命令形は表示しません。
- 文法の[PDF](ラフカ語文法.pdf)・[Markdown](ラフカ語文法.md)を配布。

## 語彙を編集する

所有者 `jinubbbo5454-rgb` だけが編集できます。辞書上部の「所有者ログイン」でGitHubトークンを入力して認証し、「語彙を追加」、または各語の「編集」「複製して追加」を選べます。見出し、品詞、性・分類、数の制限、意味、祖語型、活用・曲用、関連語を変更できます。活用・曲用は見出し・性・分類・語幹から自動補完され、入力の変更に追随します。Ⅰ・Ⅱ型などの斜格語幹や、不規則な現在語幹は指定できます。個別の語形を修正した場合は例外として保持され、「自動」で補完形に戻せます。複数形なし・複数のみ・無主語の指定も反映します。補完の設定と例外形は、保存後の再編集でも引き継がれます。

関連語の関係は「派生・類義・対義」から選べます。片方に追加すると相手側にも同じ関係が付き、種類の変更・削除・取り消しも両側に反映します。両側の変更を一緒に保存します。公開した関連語と相互リンクは、ログインせずに閲覧できます。「派生語」「派生元」は「派生」に統一し、以前の下書きやバックアップも読み込み時に変換します。見出し語や日本語の意味を入力して候補を絞り込み、品詞・意味を確認して選べます。クリック・タップ、または上下キー＋Enterで選択できます。

編集画面の「保存して公開…」で未公開の変更一覧を開き、「公開する」で辞書へ反映します。端末だけに保存する場合は「下書きに保存」を選びます。既存の下書きは上部の「未公開の変更を公開…」から公開できます。トークンの対象リポジトリを `lafca-dictionary`、Contents権限をRead and writeにしてください。トークンはページのメモリー内だけで保持し、「編集を終了」・ページ移動時に破棄します。再読み込み後は再認証が必要です。未公開の下書きは端末に保持され、所有者の認証後に復元します。公開保存時にも所有者を再確認し、第三者からの変更はGitHub側の権限で拒否されます。[GitHubのトークン管理](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)

公開時はHTML・編集データ・照合情報を一つのコミットで更新します。別の語の変更は統合し、同じ語の競合は上書きを止めます。GitHub Pagesへの反映には少し時間がかかります。「変更をバックアップ」「変更を読み込む」で未公開の編集を別の端末へ移せます。

語彙の正本は `index.html` に埋め込まれたデータと、画面から追加・編集した語彙を記録する `edits.json` です。画面ソースや文法を更新するときは、作業フォルダーの `辞書/export_pages.py` が語彙データを保ったまま `index.html` を包み直します。空のファイルや古いコピーで上書きしないでください。既存項目のIDは変更しないでください。

`index.html`は単体でも動く辞書です。GitHub Pagesはmain直下から配信します。`.nojekyll`を維持してください。

文法資料のハッシュと配布物の照合情報は`version.json`にまとめています。
