# ラフカ語辞書

ラフカ語プロジェクト専用の辞書公開リポジトリです。

**[辞書を開く](https://jinubbbo5454-rgb.github.io/lafca-dictionary/)**

- lafca2の統一辞書から整理した637項目と、文法から補足した生産的な接辞6項目を収録。
- 借用人名42語（男性27・女性15）を収録。性・読み・明記された斜格語幹を保持し、単数の五格を表示します。「借用人名」タグから一覧を表示できます。
- 品詞は名詞・代名詞・動詞・形容詞・連体詞・副詞・前置詞・接続詞・小辞・間投詞。接辞・慣用句は項目種別で選び、基数・序数は品詞を横断して絞り込めます。
- 品詞・性・型による絞り込み、変化形からの検索。動詞は「活用」、それ以外の屈折語は「曲用」で語形表を表示。
- 名詞の固定・Ⅰ・Ⅱ型、動詞の交替種類・非交替・母音幹・不規則、形容詞の語幹型を表示。
- `manča`・`bidašta`・`höri` は男性・複数のみの独立名詞として収録し、対応する語からリンクで参照できます。`fissa` や人名など79語は「複数形なし」と表示し、単数の五格だけを収録します。
- `-aq`派生名詞や`čaq`の曲用も収録。規則的な動名詞は独立見出しにせず、元の動詞の語形として扱います。`gessad`・`humad`・`sibad` の曲用は `gassen`・`homen`・`seben` の活用欄で参照できます。
- 総称や構文説明を見出しにせず、独立した意味・用法の根拠がある語彙だけを登録。語形の明記や定型句の一例だけでは語彙化と認定しません。非生産的な `-ča` と化石的な `-t-` は独立登録せず、`horča` などの派生語を収録。
- 祖語型は「祖語型：*…」に統一し、原資料の注記や表外の語形は表示しません。母音幹の曲用・活用と子音接合を含め、すべての語形を収録しています。無主語動詞の存在しない人称形・命令形は表示しません。
- 文法の[PDF](ラフカ語文法.pdf)・[Markdown](ラフカ語文法.md)を配布。

## 語彙を編集する

辞書上部の「編集」から「語彙を追加」、または各語の「編集」「複製して追加」を選べます。見出し、品詞、性・分類、数の制限、意味、祖語型、活用・曲用、関連語を変更できます。活用・曲用は見出し・性・分類・語幹から自動補完され、入力の変更に追随します。Ⅰ・Ⅱ型などの斜格語幹や、不規則な現在語幹は指定できます。個別の語形を修正した場合は例外として保持され、「自動」で補完形に戻せます。複数形なし・複数のみ・無主語の指定も反映します。補完の設定と例外形は、保存後の再編集でも引き継がれます。

「この端末に保存」はブラウザー内の保存です。公開するには「変更を保存…」→「GitHubに保存」を使います。トークンの対象リポジトリを `lafca-dictionary`、Contents権限をRead and writeにしてください。トークンは保存しません。[GitHubのトークン管理](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)

公開時はHTML・編集データ・照合情報を一つのコミットで更新します。別の語の変更は統合し、同じ語の競合は上書きを止めます。GitHub Pagesへの反映には少し時間がかかります。「変更をバックアップ」「変更を読み込む」で未公開の編集を別の端末へ移せます。

`edits.json` が画面から追加・編集した語彙の正本です。元資料から辞書を再生成するときも、このファイルを引き継いで適用してください。空のファイルや古いコピーで上書きしないでください。既存項目のIDは変更しないでください。

`index.html`は単体でも動く辞書です。GitHub Pagesはmain直下から配信します。`.nojekyll`を維持してください。

資料のハッシュと配布物の照合情報は`version.json`、収録内容は[収録情報](収録と未確定事項.md)にまとめています。
